# MIPS Emulator
This is a cross-platform emulator for the MIPS architecture, capable of running executables generated by my [assembler](https://github.com/pclava/mips_assembler).
The emulator only supports the file format generated by the assembler/linker, though could feasibly be tweaked to accept other file formats.

This is the **kernel version** of the emulator, written specifically to support [yeast](https://github.com/pclava/yeast), my kernel written for MIPS.

## Installation
To install, download one of the available binaries under **Releases**, or build the project yourself:

`$ cmake -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DSDL_X11_XSCRNSAVER=OFF -DSDL_X11_XTEST=OFF -DSDLTTF_VENDORED=ON`

`$ cmake --build build`

`$ cmake --install build --prefix dist`

The executable will be in `dist/bin`

## Usage
The emulator expects the kernel executable and a disk image (see the yeast README). It can be run with

`$ ./MIPSEmulator <kernel executable> <disk image>`

The kernel executable must have been generated by the linker, and disk image by `mkfs`.

## Notes
The emulator is little-endian.

The list of supported instructions and their opcodes can be found in `InstructionSet.cpp`.

The font is courtesy of VileR at https://int10h.org/oldschool-pc-fonts/.
